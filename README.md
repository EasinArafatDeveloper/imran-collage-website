## 🌟 মূল ফিচারসমূহ (Key Features)

### 1. 🎨 ডায়নামিক সাইট থিম ও কন্টেন্ট কাস্টমাইজার (Theme & Content Control)
- **সরাসরি এডমিন প্যানেল থেকে ওয়েবসাইটের সবকিছু পরিবর্তন**:
  - **লোগো ও ব্র্যান্ডিং**: ওয়েবসাইট ব্র্যান্ডের নাম, ট্যাগলাইন, আইকন ও কাস্টম লোগো ইমেজ।
  - **হিরো সেকশন টেক্সট**: টপ ব্যাজ, মূল শিরোনাম, গ্রেডিয়েন্ট রঙিন হাইলাইট শব্দ, সাবটাইটেল এবং বাটন টেক্সট।
  - **ন্যাভবার ও বাটন টেক্সট**: প্রতিটি মেনু ট্যাব ও লগইন বাটনের নাম পরিবর্তন।
  - **ফুটার ও যোগাযোগের তথ্য**: ক্যাম্পাস ঠিকানা, সাপোর্ট ইমেইল, ফোন নম্বর ও সোশ্যাল মিডিয়া লিংক।
  - **লাইভ ইন্টারঅ্যাক্টিভ প্রিভিউ (Live Preview)**: এডমিন পরিবর্তনের সাথে সাথে লাইভ প্রিভিউ দেখতে পান।

---

### 2. 🎟️ আল্ট্রা-প্রিমিয়াম ডিজিটাল কিউআর টিকেট পাস (Concert VIP Pass)
- বাস্তবসম্মত **সিনেমা ও কনসার্ট ভিআইপি বোর্ডিং পাস** স্টাইল।
- পারফোরেটেড টিয়ার লাইন ও সার্কুলার পাঞ্চ নচ ডিজাইন।
- **⚡ ১-ক্লিকে সরাসরি HD ইমেজ ডাউনলোড (`Download my ticket`)**: হাই-রেজুলেশন PNG ছবি হিসেবে ডিভাইসে সেভ হয়।
- **🖨️ সিঙ্গেল-পেজ আইসোলেটেড প্রিন্ট ও PDF সংরক্ষণ**: কোনো অতিরিক্ত ফাঁকা পৃষ্ঠা ছাড়া পারফেক্ট সাইজে প্রিন্ট হয়।
- ইনস্ট্যান্ট কিউআর কোড এবং বুকিং আইডি কপি করার সুবিধা।

---

### 3. 🚀 ইভেন্ট এক্সপ্লোরার ও স্মার্ট রেজিস্ট্রেশন (Event Management)
- **স্মার্ট ফিল্টারিং**: টেক ফেস্ট, কালচারাল, সেমিনার, ওয়ার্কশপ ও স্পোর্টস ক্যাটাগরি।
- ডিপার্টমেন্ট ভিত্তিক ফিল্টার এবং ফ্রি/পেইড ফিল্টারিং।
- **লাইভ সিট ক্যাপাসিটি ট্র্যাকিং** ও অটোমেটিক ওয়েটিং লিস্ট ম্যানেজমেন্ট।
- বিকাশ, নগদ ও রকেটের রিয়ালিস্টিক সিমুলেটেড মোবাইল ব্যাংকিং পেমেন্ট গেটওয়ে।

---

### 4. 📸 ক্যাম্পাস স্মৃতি ও ফটো গ্যালারি (Campus Memories)
- বিশ্ববিদ্যালয়ের স্মরণীয় মুহূর্ত ও ইভেন্টের আকর্ষণীয় ছবির গ্যালারি।
- এডমিন প্যানেল থেকে সহজেই নতুন ছবি আপলোড, ক্যাটাগরি নির্ধারণ ও ডিলিট করার ব্যবস্থা।
- হোম পেজে রিয়েল-টাইম ৪টি হাইলাইট ছবি এবং "See All" গ্যালারি পোর্টাল।

---

### 5. 🏛️ বিশ্ববিদ্যালয় ক্লাব ও ফোরাম হাব (Clubs Directory)
- আইটি ক্লাব, কালচারাল ফোরাম, ডিবেট ক্লাব, রোবোটিক্স সোসাইটি ইত্যাদির প্রোফাইল।
- সরাসরি স্টুডেন্টদের এক-ক্লিকে ক্লাবে জয়েন রিকোয়েস্ট পাঠানোর সুবিধা।
- এডমিন প্যানেল থেকে নতুন ক্লাব তৈরি ও পরিচালনা।

---

### 6. 🛡️ ফুল-ফিচার্ড এডমিন কন্ট্রোল টাওয়ার (`/admin`)
- **ইভেন্ট ক্রুড (CRUD)**: নতুন ইভেন্ট তৈরি, এডিট, স্ট্যাটাস পরিবর্তন ও ডিলিট।
- **ইউজার ডিরেক্টরি**: সকল শিক্ষার্থী ও এডমিন তালিকা, রোল পরিবর্তন ও প্রোফাইল ভিউ।
- **পার্টিসিপ্যান্ট ডিরেক্টরি**: ইভেন্ট অনুযায়ী এনরোল্ড সকল শিক্ষার্থীর তালিকা ও CSV এক্সপোর্ট।
- **লাইভ কিউআর স্ক্যানার**: গেটে উপস্থিতির জন্য ওয়েবক্যাম বা ম্যানুয়াল কিউআর কোড স্ক্যানার।
- **সিকিউরিটি অডিট লগ**: সিস্টেমের সকল সংবেদনশীল অ্যাক্টিভিটি ট্র্যাক করা।
- **অ্যানালিটিক্স চার্টস**: গ্রাফ ও চার্ট দিয়ে পার্টিসিপেশন অ্যানালিটিক্স।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

| লেয়ার | টেকনোলজি |
| :--- | :--- |
| **Frontend Framework** | [Next.js 14](https://nextjs.org/) (App Router, Server & Client Components) |
| **Language** | [TypeScript](https://www.typescriptlang.org/) (Strict Mode) |
| **Styling & UI** | [Tailwind CSS](https://tailwindcss.com/), Glassmorphism, Dark/Light Mode |
| **Animations** | [Framer Motion](https://www.framer.com/motion/), Canvas Confetti |
| **Icons** | [Lucide React](https://lucide.dev/) |
| **Image & QR Engine** | [html-to-image](https://github.com/bubkoo/html-to-image), [qrcode.react](https://github.com/zpao/qrcode.react) |
| **Database** | [MongoDB Atlas](https://www.mongodb.com/) with [Mongoose ODM](https://mongoosejs.com/) |
| **Authentication** | JSON Web Tokens (JWT) in HttpOnly Cookies & Bcryptjs Password Hashing |

## 🚀 ইনস্টলেশন ও সেটআপ (Getting Started)

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/EasinArafatDeveloper/imran-collage-website.git
cd imran-collage-website
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ৩. এনভায়রনমেন্ট ভেরিয়েবল কনফিগার করুন
প্রজেক্টের রুট ডিরেক্টরিতে `.env.local` ফাইল তৈরি করুন:
```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_super_secret_jwt_key_2026
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে **`http://localhost:3000`** ওপেন করুন।

## 📡 রেস্ট এপিআই তালিকা (REST API Directory)

| মেথড | এন্ডপয়েন্ট | বিবরণ |
| :--- | :--- | :--- |
| `GET` / `PUT` | `/api/settings` | সাইট থিম, লোগো, শিরোনাম, বাটন ও ফুটার সেটিংস |
| `GET` / `POST` | `/api/events` | ফিল্টারসহ সকল ইভেন্ট ফেচ ও নতুন ইভেন্ট তৈরি |
| `GET` / `POST` | `/api/registrations` | স্টুডেন্ট রেজিস্ট্রেশন ও কিউআর টিকেট জেনারেশন |
| `GET` / `POST` | `/api/gallery` | ক্যাম্পাস স্মৃতি ছবির গ্যালারি পরিচালনা |
| `GET` / `POST` | `/api/clubs` | বিশ্ববিদ্যালয় ক্লাব ও ফোরাম তালিকা |
| `POST` | `/api/attendance/verify-qr` | কিউআর কোড স্ক্যান করে উপস্থিতি যাচাই |
| `POST` | `/api/auth/login` | সিকিউর ইউজার অথেনটিকেশন ও সেশন তৈরি |
| `POST` | `/api/auth/register` | নতুন স্টুডেন্ট অ্যাকাউন্ট ও প্রোফাইল তৈরি |
| `GET` | `/api/admin/audit-logs` | সিস্টেম সিকিউরিটি অডিট হিস্টোরি |
| `POST` | `/api/seed` | ডাটাবেসে ডেমো ইভেন্ট ও ডাটা সিড করা |
